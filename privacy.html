Privacy Policy

Blind Spot Studio Uploader · Last updated October 1, 2026

Who this applies to

Blind Spot Studio Uploader ("the app") is a private tool used only by its owner to publish videos on the owner's own YouTube channels. It is not available to the public, and no other person's Google account is ever connected to it.

What data the app accesses

When the owner signs in with Google, the app uses the YouTube Data API on the owner's own channels to:

  • upload videos and thumbnails, and set each video's title, description, tags and scheduled publish time;
  • read the channel's list of uploaded and scheduled videos, so videos are not booked on the same day;
  • change the privacy or schedule of the owner's own videos when a publishing problem has to be fixed.

The app does not read comments, messages, subscribers' personal data, or anything outside the owner's channels.

How data is stored

  • Google sign-in tokens are stored only on the owner's own computer.
  • The app keeps a local log of the videos it uploaded (title, video ID, publish time) on that same computer.
  • No data is sent to any server operated by the app; it talks only to Google's own APIs.

Sharing

The app never sells, shares, or transfers Google user data to anyone, and does not use it for advertising. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also ends the app's access.

Changes

If this policy changes, the updated version is posted on this page with a new date.
